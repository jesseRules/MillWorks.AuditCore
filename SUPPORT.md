# Support

## Getting Help

- **Bug reports**: [GitHub Issues](https://github.com/jesserules/millworks.auditcore/issues) using the bug report template
- **Feature requests**: [GitHub Issues](https://github.com/jesserules/millworks.auditcore/issues) using the feature request template
- **Questions & discussion**: [GitHub Discussions](https://github.com/jesserules/millworks.auditcore/discussions)
- **Security vulnerabilities**: See [SECURITY.md](SECURITY.md) for responsible disclosure

## Before Filing an Issue

1. Check existing [issues](https://github.com/jesserules/millworks.auditcore/issues) for duplicates
2. Include your .NET version, OS, and MillWorks.AuditCore version
3. Provide a minimal reproduction if possible
